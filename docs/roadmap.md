# Roadmap

What this plugin set plans to add.

This is a plan, not a commitment. Items may change, move, or be dropped.

Package names below are provisional.

---

## Committed

### Plugin market

A place inside AI Shell to browse DSH plugins and install them.

*Provisional package: `aishell-dsh-market`.*

### Huawei Cloud skills

The catalogue of Huawei Cloud's official skills, browsable and installable from
inside AI Shell.

*Provisional package: `aishell-dsh-huaweicloud-skills`.*

### Huawei Cloud resource connectors

Connections to Huawei Cloud resources such as RDS, DMQ, and CCE, so the agent
can reach them without the user arranging the network and permissions.

*Provisional package: `aishell-dsh-huaweicloud-connector`.*

## Exploring

Directions under consideration. An item may still be dropped.

## Not planned

Things this repository does not intend to do, with the reason.
